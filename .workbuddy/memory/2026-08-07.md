## 模块实现：MetaSounds 程序化音频节点图 (对标 UE5 MetaSounds)
- 用户明确："我自己搞了3年，你只需写模块实现代码"。已停止流程讨论，转向直接写代码。
- 选定净缺口模块：项目已有 EQS/Lumen/材质分层/世界流式等真实实现，但**缺 MetaSounds（节点化实时音频合成）**——Audio 子系统有 WASAPI/miniaudio/DSP/混音后端但只有采样播放。
- 新增 `ShanyuEngine/Audio/MetaSounds/` 4 文件（数据驱动音频图，同构 UE MetaSound）：
  - `MetaSoundCore.cs`：数据模型（引脚/节点/连接/图/状态/参数/克隆）
  - `MetaSoundRuntime.cs`：执行机（样本精确求值+备忘录+状态按实例隔离）+ `MetaSoundVoice`（与 `AudioSource.ReadSamples` 同签名，可直插混音器）+ `MetaSoundWav`（16bit PCM 写出）
  - `MetaSoundPresets.cs`：SubBass/Pluck/NoisePerc/FilterSweep 四个示例 patch（兼作集成范例）
  - `MetaSoundTests.cs`：纯逻辑自检（音高/包络形状/滤波衰减/实例隔离/WAV），无需 GPU
- 已修两处真实 bug：实例用克隆 id 作字典键但 OutputNodeId/参数绑定仍是原始 id；Trigger() 无法产生上升沿重触发（改为触发前清零各包络 prevTrig）。
- csproj 用 `EnableDefaultCompileItems=false` + 显式 `Audio\**\*.cs`，新子目录文件会自动纳入编译。
- **未编译验证**（无 dotnet SDK）。运行方式：`new MetaSoundVoice(MetaSoundPresets.Pluck()).RenderToClip(0.5f,1)` 或 `MetaSoundTests.RunAll(outDir)`。
- 后续可选缺口模块：Substrate 材质 / ControlRig / World Partition / Replication Graph·Iris（用户指定即可写）。
