# Basic3D Template

This is the minimal Yama Engine 1.0 starter project.

It contains:

- `yama.project.json`: project manifest
- `Content/Scenes/Main.yama`: startup scene
- `Content/Materials/Default.shmat`: default preview material
- `Content/Assets`: imported assets folder
- `Builds`: exported runtime packages

Open `Content/Scenes/Main.yama` in YamaEditor, then use `Export Demo` to create a playable runtime package.
