# Basic3D Template

This is the minimal Shanyu Engine 1.0 starter project.

It contains:

- `shanyu.project.json`: project manifest
- `Content/Scenes/Main.shanyu`: startup scene
- `Content/Materials/Default.shmat`: default preview material
- `Content/Assets`: imported assets folder
- `Builds`: exported runtime packages

Open `Content/Scenes/Main.shanyu` in ShanyuEditor, then use `Export Demo` to create a playable runtime package.
