# 与行业 SOTA 引擎的真实差距（2026-11-26，诚实基线）

> 用户目标：「一直做改进，直到引擎达到行业 SOTA 级别」。
> 本文档给出**可判定的差距清单**，并明确哪些在本环境物理上不可能完成。
> **结论先行：不能宣称达到 SOTA，也不可能在单轮/单会话内达成。**

## 层 1：真机 GPU / 渲染（本环境做不到）

| 缺口 | 为什么沙盒做不到 |
|---|---|
| Vulkan/D3D12 后端真实 GPU 帧、PBR/Lumen 级管线端到端 | 无 GPU、无驱动、无窗口系统 |
| `0xC0000005` 原生崩溃 minidump 定位 | 需要 Windows 真机 + 调试器 |
| 百万粒子 / 1000+ 刚体堆叠压测、帧时间预算 | 需要 GPU + 性能采样器 |
| 多线程 job graph / task stealing | 需要真机并发剖析，CI 单 runner 不能代表 |

## 层 2：平台与导出（本环境做不到）

iOS / Android / Web(WASM) / 主机 SDK（PS5/Xbox/Switch）导出模板、
代码签名、平台 ABI、商店合规 —— 全部需要各平台 SDK 与授权，
仓库里目前只有 5 个适配层占位。

## 层 3：生态与工程化（需要团队与时间）

编辑器 UX 打磨、GDScript/C# 脚本 VM 的完整语义与调试器、资产商店、
文档/教程/示例工程、插件生态、多版本兼容策略、CI 矩阵（多 OS/多编译器）、
长期回归与社区 issue 验证 —— 这些不是"写几个 .cs"能补的。

## 层 4：专有与不可复现

RAGE 的破坏/流体、Euphoria 的主动布娃娃、Chaos 的缓存破坏、
Nanite/Lumen 的几何与光照 —— 均为未公开专有实现，
**不存在公开可对照的验收口径**，因此连"差距"都无法量化。

## 沙盒环境的硬约束（不可绕过）

- 本地无 `.NET` / `csc` / `mono` / `msbuild` / `cargo`；
  所有编译验证都通过**云端 GitHub Actions** 完成（`-warnaserror` + Test + Smoke）。
- 无 GPU、无 Windows 真机、无主机 SDK、无平台签名能力。
- 单人、单会话、无外部用户验证。
- token 为 `repo` 全权限且已出现在聊天记录里，有效期有限。

## 本轮（第十轮）在 SOTA 方向上的真实增量

- CCD 从「整帧保守膨胀」升级为「迭代式 CA」（行业 CCD 的标准形态，线性化版）
- 接触流形从「单面 + Id 冲突风险」升级为「多面 + `(faceId,pointId)` 分段 + 几何缩减」
- 全部默认关闭、零回归、121 项断言云端真实执行

**这缩小的是「算法层的可判定差距」，没有缩小 G4–G8。**

## 结论

继续改进可以做的是：**把可判定层（G0–G3）做深、做严、做到无假绿**。
「行业 SOTA」需要 G4–G8，本环境物理上不具备条件，因此
**不能宣称，也不应承诺在若干轮内达成**。任何声称"已达到 SOTA"的交付
都会与本文档矛盾，不予采纳。
