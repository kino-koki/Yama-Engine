Honest Note

Yama is a research / prototype engine today: it cannot — and should not — be used to ship a commercial game right now. This table exists to explain design intent and real gaps, not to claim parity with any mature engine. If you need to ship now, use Unity / Unreal / Godot. If you want to read and shape every line of an engine — you're welcome here.
