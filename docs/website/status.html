05 / Honest Status

我们告诉你真实状态，
而不是营销话术。

很多引擎官网只展示成功的部分。Yama 反过来 — 我们把已完成和未完成的事情同样清楚地摆出来，因为透明才是开源项目最大的价值。这里按成熟度、编译结果、路线图三段完整呈现。

05-A Maturity
成熟度

哪些是真的，
哪些还需要时间。

Yama 的物理、AI、动画、音频、ECS 系统在算法层面已完整实现。渲染管线中的 PBR、级联阴影、骨骼蒙皮已接入主管线。但 ReSTIR 全局光照、路径追踪、MicroCluster 等高级特性目前停留在算法原型阶段。

所有托管项目在 2026-11-01 达到 0 编译错误，但编译通过不等于 GPU 已端到端验证 — Vulkan 运行时崩溃仍需在真实硬件上调试。

  • 物理引擎的 GJK / EPA / SAT 碰撞检测、9 种关节约束已全部实现，有单元测试覆盖
  • 渲染管线的 PBR + 级联阴影 + TSR 已接入 SceneRendererReal，但尚需在独显机器上验证运行时稳定性
  • ReSTIR、SVGF、路径追踪已写出完整算法代码，等待接入主管线并在 GPU 上跑通
  • DCC 桥接（Blender / Maya / Max）处于骨架级实现，能收发基本数据，但未做生产级测试
  • C++ 原生桥接（YamaEngineBridge）需要 Visual Studio MSBuild 单独编译，暂未纳入自动化 CI

05-C Roadmap

下一步：
让它真的跑起来。

从"能编译"到"能跑"，中间隔着一个真实的 GPU 端到端验证。这是 Yama 当前最集中的一块工作。

已完成 · 2026-11-01
全部托管项目编译清零
引擎库、编辑器、测试、运行时与桥接工程全部 0 错误。P0 崩溃防御补丁已落地：PSO 空句柄防护、管线创建校验、跨帧缓存清空。
进行中 · Phase 1
真实 GPU 端到端验证
在独显 Windows 机器上复现并消除 VulkanPipelineState 0xC0000005 崩溃，开启 Khronos 验证层定位根因，把渲染闭环从第一个三角形推到完整 PBR 场景。
规划中 · Phase 2
高级渲染特性接入主管线
把 ReSTIR、SVGF、路径追踪、MicroCluster 从算法原型接进 SceneRendererReal，在真实 GPU 上验证性能与画质。
规划中 · Phase 3
工程卫生与 CI 闭环
清理根目录的历史分析文档与 D3D12 残留代码，补齐 C++ 桥接工程的自动化构建覆盖，建立完整的 CI/CD 流水线。
