Quick Start · 快速上手

十分钟，
把引擎跑起来。

不需要 Unreal 的 100GB、不需要 Unity 的激活流程。克隆仓库、装一个 .NET SDK，从编译到打开编辑器，每一步都真实可验证。

克隆仓库
Q-1 Prerequisites
环境要求

开始之前，
你需要三样东西。

Windows 10/11 x64 · .NET SDK 10.0（仓库 global.json 锁定 10.0.203）· 支持 Vulkan 1.3+ 的显卡与驱动。C++ 桥接与编辑器窗口需要 Visual Studio 2022（含桌面开发工作负载），但只跑引擎库和测试不需要它。

01

拿到代码

约 1 分钟 · Git

克隆仓库并进入目录。仓库不大，克隆很快。

git clone https://github.com/kino-koki/Yama-Engine.git cd Yama-Engine
02

还原依赖

约 2 分钟 · dotnet restore

还原 NuGet 包。Silk.NET（Vulkan 绑定）、xUnit 等依赖会自动下载。

dotnet restore YamaEditor.sln
Note仓库带 NuGet.config，国内网络建议先确认能访问 api.nuget.org。
03

编译引擎核心库

约 1 分钟 · 0 错误 0 警告

YamaEngine 是引擎核心库（约 32 万行 C#）。当前全部托管项目 0 错误 0 警告通过编译，任何新警告都会被 -warnaserror 直接判失败。

dotnet build YamaEngine\YamaEngine.csproj -c Debug // 预期输出（尾部） // Build succeeded. 0 Warning(s) 0 Error(s)
04

跑测试套件

约 3 分钟 · 1559 用例

测试覆盖物理解析解、ECS、动画状态机、渲染后处理等。跑完全绿说明你本机环境没问题。

dotnet run --project YamaEngine.Tests\YamaEngine.Tests.csproj // 预期输出（尾部） // All YamaEngine tests passed.
05

打开编辑器

约 2 分钟 · WinUI 3 + Vulkan

编辑器是 WinUI 3 外壳内嵌 Vulkan 视口。首次启动会编译着色器，稍等片刻。

dotnet build YamaEditor\YamaEditor.csproj -c Debug dotnet run --project YamaEditor\YamaEditor.csproj
Honest noteVulkan 运行时在某些驱动上仍有稳定性问题（历史 0xC0000005），这是当前最优先修复项 — 遇到崩溃请带着日志提 Issue。
06

改一行，看热加载

可选 · Roslyn 脚本

在 YamaCLI 沙箱里改一句日志，体验运行时脚本热加载 — 不用重启进程。

dotnet run --project YamaCLI\YamaCLI.csproj
Next Step
