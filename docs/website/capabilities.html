深入 · 三个系统怎么协作

九张卡片是横向的"有什么"，这一节纵向讲"怎么协作"。游戏里一个移动的箱子，其实同时经过物理、渲染、ECS 三层：

  1. ECS 的 Transform 组件持有位置与旋转，RigidBody 组件声明它参与物理模拟。
  2. 物理系统的 solver 在固定步长里推进速度与位置，写回 Transform。
  3. 渲染系统读取 Transform，写入统一的模型矩阵缓存，再交给 Vulkan 的 push constant / UBO。
  4. 动画系统通过骨骼蒙皮修改顶点，Motion Matching 决定用哪段动画，全部在 GPU 侧完成。
  5. 音频系统按监听者与声源的距离计算 3D 衰减，输出到 WASAPI / Miniaudio。
Honest Note

文件数表示"有多少代码"，不表示"已经稳定"。渲染管线成熟度 60%，DCC 桥接 30% — 具体数字在 真实状态 页有逐项评估。
