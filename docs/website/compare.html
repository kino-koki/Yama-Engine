Honest Note · 诚实声明

Yama 当前是研究 / 原型级引擎：它不能、也不应该在今天被用来交付商业游戏。这张表的存在是为了说明设计取向与差距，而不是宣称已经追平任何成熟引擎。如果你需要"现在就能发货"，请选 Unity / Unreal / Godot；如果你想读懂一个引擎的每一行并参与塑造它 — 这里欢迎你。

山雨欲来风满楼。
唐 · 许浑《咸阳城东楼》

编译错误已经清零，好比山雨将至；而真正的 GPU 端到端验证还没有跑通 —— 风尚未满楼。这是引擎此刻的真实状态，也是下一阶段要集中攻克的事。
