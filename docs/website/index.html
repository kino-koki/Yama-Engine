/01 — Why

为什么做 Yama

商业引擎封闭源码、抽成昂贵、深度绑定生态；开源引擎要么能力有限，要么只是玩具。Yama 试图走出第三条路：能力完整、代码透明、真正开放。这一页讲清动机、设计哲学与三条不可妥协的原则。

进入模块 /02 — Capabilities

九大核心系统

渲染管线、物理引擎、人工智能、动画、音频、ECS、一体化编辑器、DCC 桥接、网络与脚本。九个系统逐一展开：每个都有实际代码实现，文件数与关键算法都标注在页面上。

进入模块 /03 — Scenarios

使用场景

3D 游戏原型、地形与场景编辑、DCC 工具实时桥接 — 三大工作流各展开一整页。从建模到部署、从视觉脚本到 LiveLink，Yama 试图覆盖桌面 3A 开发的每一个环节。

进入模块 /04 — Architecture

六层架构

D3D12 已废弃并从工程中排除，整个引擎只有一个图形后端 — Vulkan 1.4。这一页讲清六层结构、RHI 抽象、模块依赖关系，以及为什么"一个后端"是性能与可维护性的关键决策。

山雨欲来
风满楼。

Yama 的名字取自"嵯峨"之山势，取意的则是唐诗里最著名的一句风雨前奏。我们把许浑的《咸阳城东楼》八句完整请进站内 — 竖排、大字、六段日落色阶，做成一页可以慢慢读的艺术排版。

引擎要面对 GPU 崩溃、验证层、跨帧缓存这类具体的麻烦，诗也一样 — 咸阳城东楼上那一晚的风，吹了一千多年。
