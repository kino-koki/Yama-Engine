/01 — Why

Why build Yama

Commercial engines are closed-source and expensive; open engines are limited or toy-grade. Yama tries a third path: capable, transparent, truly open. This page covers the motivation and three non-negotiable principles.

Enter module /02 — Capabilities

Nine core systems

Rendering, physics, AI, animation, audio, ECS, integrated editor, DCC bridges, networking & scripting — each with real code, file counts and key algorithms documented on the page.

Enter module /03 — Scenarios

Use cases

3D game prototyping, terrain & scene editing, live DCC bridging — three workflows, one page each. From modeling to deployment, Yama aims to cover every step of desktop AAA development.

Enter module /04 — Architecture

Six-layer architecture

D3D12 was removed from the project entirely — the engine has exactly one graphics backend: Vulkan 1.4. This page explains the layers, the RHI abstraction, and why "one backend" is the key decision.
