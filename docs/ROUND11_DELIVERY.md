# 第十一轮交付：算法层继续深化（已推 main）

## 本轮四件实质改进

1. **`YrFullRotationalCa`**：每步把姿态用 `exp(ω·t/2)⊗q0` 精确积分、
   重枚举 15 轴算瞬时 SAT 分离，替代第十轮 `spin·t` 从 0 累积的线性化上界
   → 更精确且仍不漏报。零角速度逼近解析 TOI，带角速不早报于线性化 CA。
   `MaxIterations=128`：带旋转时 CA 几何级数收敛（真实固定步实测最大 34 次，
   人为放大 dt 可达 126 次），这是性能代价而非精度放宽；同时修掉
   「float32 停滞被误判成 −1」的潜在漏报。
2. **`IncidentFaceFor` + 多面各自重选入射面**：修正旧启发式「落到侧面」的问题，
   每个参考面按自己的法向选 B 上真正朝向它的面，深度沿该面法向测。
   单面 `BuildTagged`/`Build` 一字未改。
3. **`ReduceByWrench`**：接触缩减从几何 farthest-point 改为 6D wrench 行
   `[n, r×n]` 的 modified Gram-Schmidt 线性独立性；`BuildMultiFaceReduced`
   同时改用物理侵入深度。
4. **15 项新回归** → 十一轮累计 **136 项**物理断言（9 + 14×8 + 15），
   云端真实执行。第十一轮提交信息里的「135 项（9+14×9）」为笔误，此处更正。

## 诊断轮（CI 红灯 → 全绿）

第一次红灯回读到 3 个失败，同一根因：裁剪交点继承起点 Id，第十轮
`BuildMultiFace` 直接写 `fid*4+cp.Id` → 同一参考面内多交点继承同一顶点时
Id 冲突（第十轮布局未触发，本轮各自入射面把它暴露）。修法：面内维护
`used[4]` 槽位表，优先保留原顶点 Id、冲突时分配最小空闲槽位。
